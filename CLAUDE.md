# PIA - Claude Instructions

## Proyecto

PIA es un sistema de Inteligencia Artificial autónomo enfocado en análisis de mercados, trading y aprendizaje continuo.

El objetivo es crear una arquitectura basada en múltiples agentes capaces de analizar información, tomar decisiones, evaluar resultados y mejorar con el tiempo.

---

# Arquitectura actual

## AI Brain

Cerebro principal del sistema.
Responsable de coordinar agentes, analizar información y tomar decisiones.

## Memory Agent

Responsable de gestionar recuerdos, experiencias y conocimiento.

## Memory Manager

Administra almacenamiento, recuperación y organización de memoria.

## Market Agent

Obtiene información del mercado financiero.

## Trading Analyst

Analiza oportunidades, indicadores y condiciones del mercado.

# Reglas de desarrollo

Antes de modificar código:

1. Leer la arquitectura existente.
2. Revisar archivos relacionados.
3. No eliminar funcionalidades sin autorización.
4. Mantener código modular.
5. Separar responsabilidades por agentes.
6. Priorizar soluciones escalables.

---

# Estructura esperada

Cada agente debe tener:

- Código independiente.
- Configuración propia.
- Logs.
- Manejo de errores.
- Documentación.

---

# Flujo de trabajo

Antes de comenzar cualquier tarea leer:

- CURRENT_STATE.md
- TODO.md
- ARCHITECTURE.md
- DECISIONS.md

Después de realizar cambios actualizar:

- CURRENT_STATE.md
- TODO.md
- CHANGELOG.md

# Objetivo final

Crear una IA autónoma capaz de:

- Analizar mercados.
- Crear estrategias.
- Ejecutar análisis.
- Aprender de errores.
- Recordar experiencias.
- Mejorar decisiones.
- Trabajar con múltiples agentes.
